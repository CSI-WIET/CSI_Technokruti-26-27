Drop your own licensed audio file here, named exactly:

    theme-song.mp3

The site's music toggle (bottom-left, appears once the intro finishes)
automatically detects this file — nothing else to configure. If the file
isn't present, the toggle simply stays hidden and the site behaves
normally.

IMPORTANT — this folder intentionally ships empty.
This project does not include Michael Jackson's "Thriller" or any other
commercially copyrighted track. You'll need to supply an audio file you
actually have the rights to use for this event:

  - A royalty-free / licensed-for-use track (e.g. YouTube Audio Library,
    Pixabay Music, Epidemic Sound, Free Music Archive with an appropriate
    license), or
  - A commercial song for which your event/institution has cleared the
    necessary synchronization and public-performance rights.

Keep the file reasonably small (a compressed MP3 under ~5-8MB loads much
faster than a raw WAV) and named theme-song.mp3 so SiteAudio.jsx finds it.
